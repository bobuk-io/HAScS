# HAScS 0.3.3

- The scene panel uses BobukKit, the shared bobuk.io component library, for
  keyboard hints in its footer. Each key stays next to its action.
- English, Ukrainian and Russian captions are retained. The close button,
  scene tiles, grid navigation, reordering and scene activation are unchanged.

Your Home Assistant connection, Keychain token, scene assignments and settings
are retained. Download the universal ZIP from GitHub Releases, quit HAScS and
replace the app in /Applications. This release does not add an automatic updater.
