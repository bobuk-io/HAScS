# HAScS 0.3.2

**Home Assistant Scenes Selector** — a native macOS menu-bar remote for Home Assistant scenes.

## Highlights

- Added the **Scene Dial** app icon: an ivory home inside an indigo circular
  selector with an amber highlighted segment.
- Included all standard and Retina icon sizes, from 16 to 1024 pixels, in the
  macOS app bundle. The menu-bar house symbol remains unchanged.
- Added automatic icon generation during packaging using tools included in
  macOS, and bundle validation that rejects missing or invalid icon resources.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

Download `HAScS-0.3.2-universal.zip`, unzip it, and move `HAScS.app` to Applications.
Existing Keychain credentials and saved scene assignments are preserved.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
notarization ticket. Verify the archive with `SHA256SUMS.txt` if desired.

## Notes

- Scene selection, spatial arrow-key navigation, and reordering are unchanged.
- Credentials, `.env` files, signing keys, and notarization credentials are not
  included. Release artifacts are checked for local home and build paths.
