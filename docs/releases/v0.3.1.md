# HAScS 0.3.1

**Home Assistant Scenes Selector** — a native macOS menu-bar remote for Home Assistant scenes.

## Highlights

- Fixed arrow-key navigation to follow the visible grid: **Up/Down** moves
  between rows, while **Left/Right** stays within the current row.
- Added spatial reordering with **Shift + arrow keys**, including moves between
  rows. Scene numbers and tile positions remain in sync.
- Preserved the intended column when navigating through the wide first tile
  or an incomplete final row, so vertical return trips go back to the expected
  position.
- Stopped navigation at grid edges instead of wrapping around. Normal selection
  skips unavailable scenes without changing the grid geometry; reordering still
  includes them.
- Updated the reordering hint in English, Ukrainian, and Russian.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

Download `HAScS-0.3.1-universal.zip`, unzip it, and move `HAScS.app` to Applications.
Existing Keychain credentials and saved scene assignments are preserved.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
notarization ticket. Verify the archive with `SHA256SUMS.txt` if desired.

## Notes

- Scene activation remains disabled while reordering. **Done** (Return) saves
  the order; **Cancel** (Escape) discards unsaved changes.
- Up to nine scenes are available; additional rows scroll into view.
- Credentials, `.env` files, signing keys, and notarization credentials are not
  included. Release artifacts are checked for local home and build paths.
