# HAScS 0.3.0

**Home Assistant Scenes Selector** — a native macOS menu-bar remote for Home Assistant scenes.

## Highlights

- Added a dedicated **Reorder** mode. Drag a tile onto another position to move
  it there and shift the intervening scenes. Tile positions and keys 1–9 stay
  in sync, including the featured first tile.
- Added **Done** (Return) to save the order and **Cancel** (Escape) to discard
  changes. Closing the remote also discards unsaved changes. Saved assignments
  survive app restarts and Home Assistant response-order changes.
- Blocked scene activation while reordering, including number keys and tile
  clicks. Return saves the order instead of running a scene.
- Added keyboard reordering with **Shift + arrow keys**, tile context-menu
  commands, and VoiceOver actions. Unavailable scenes can also be reordered.
- Added English, Ukrainian, and Russian translations for the new controls.
- Moved the repository to **bobuk-io/HAScS** and clarified the full product name.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

Download `HAScS-0.3.0-universal.zip`, unzip it, and move `HAScS.app` to Applications.
The app starts in the menu bar without opening a window. Existing Keychain
credentials and saved scene assignments are preserved.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
notarization ticket. Verify the archive with `SHA256SUMS.txt` if desired.

## Notes

- Up to nine scenes are available. Additional rows scroll into view.
- Scene activation affects real devices; a successful Home Assistant response
  confirms the request, not each device's final state.
- Global-hotkey registration and launch at login are not yet included.
- Credentials, `.env` files, signing keys, and notarization credentials are not
  included. Release artifacts are checked for local home and build paths.
