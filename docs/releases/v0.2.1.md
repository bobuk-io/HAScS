# HAScS 0.2.1

A native macOS menu-bar remote for Home Assistant scenes.

## Highlights

- English, Ukrainian and Russian interfaces, including settings, menus, errors
  and accessibility labels.
- A centered floating remote, opened from the menu-bar house icon or
  `hascs://scenes`.
- Keys 1–9 to activate scenes, arrows to select, Return to activate and Escape
  to dismiss.
- Home Assistant URL and token storage in macOS Keychain.
- Stable scene-number assignments across refreshes.

## Release hardening

- Resource lookup no longer embeds the builder's absolute directory.
- Debug-map object paths are removed before signing. An automated privacy check
  rejects app bundles containing local home/build paths or private key files.
- Source documentation is in English. Original code is licensed under 0BSD;
  adapted packaging scripts retain their upstream MIT license.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

Download `HAScS-0.2.1-universal.zip`, unzip it, and move `HAScS.app` to Applications.
The app starts in the menu bar without opening a window. Right-click the house
icon and choose Settings to configure Home Assistant.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
ticket. Verify the archive with `SHA256SUMS.txt` if desired.

## Notes

- Scene activation affects real devices; a successful HA response confirms the
  request, not each device's final state.
- Up to nine scenes are available. Additional rows scroll; more than nine scenes
  display a limit notice.
- Global hotkey registration, launch at login and scene reordering are not yet
  included.
- Credentials, `.env` files and signing/notarization keys are not included.
- Old plaintext files and legacy Keychain records are not automatically deleted.
